# إغلاق معايرة محرك مصفوفة القدر

الفرع: `fix/engine-calibration` · النسخة الاحتياطية: `backup/engine-before-calibration-ac87fee` (= `main` قبل المعايرة) · لم يُدمج شيء.

## الحكم النهائي: **جاهز جزئيًا**
- الحسابات الموثّقة بمصادر منشورة صحيحة بعد إصلاح واحد مؤكد (جدول الشاكرات).
- **لا يمكن إعلان المطابقة الكاملة لموقع المرجع matrix-destiny.com**: لم يُرفق أي رقم من المرجع لتاريخ 11/11/1998 (الصورتان لم تصلا)، والموقع المرجعي لا ينشر منهجه (مدفوع).
- عنصر واحد **غير محسوم**: النقاط الداخلية للخطوط المائلة (لا يوجد توثيق منشور لها).

## الخطأ الحسابي المؤكد الذي أُصلح
جدول الشاكرات كان يضع صفوف العين الثالثة والحلق والعجز بمعادلات لا يؤيدها أي مصدر (وُجدت منذ أول كوميت بلا توثيق؛ كانت `docs/matrix-audit.md` تصفها «reference unverified»). مثالان منشوران مستقلان يتفقان مع بعضهما ويخالفان الكود القديم:

| الصف | المحرك القديم (جسد/طاقة) | المصادر المنشورة (= المحرك الآن) |
|---|---|---|
| العين الثالثة | A2 / B2 (نقطة وسطى) | A+(A+E) / B+(B+E) (النقطة الخارجية x2) |
| الحلق | (A+A2) / (B+B2) | A+E / B+E (النقطة الوسطى x1) |
| القلب | (A2+E) / (B2+E) | (x1+E) — لم يتغير |
| العجز | (C2+E) / (D2+E) | C+E / D+E |

مثال 23-06-1992 (mind.university) و15-03-1990 (numato.pl): جميع الصفوف الـ7 × 3 والإجماليات تطابق المحرك الآن.
تغيير الكود محصور في كتلة الشاكرات داخل `assets/js/matrix-method-adapter.js`؛ لم يُلمس أي نص أو تصميم.
تأثير التصحيح على 11/11/1998 (جسد/طاقة/مشاعر): العين الثالثة 19/19/11 → 3/3/6، الحلق 3/3/6 → 19/19/11، العجز 7/20/9 → 17/12/11، والإجماليات 13/12/16.

## الفصل بين نوعي الإثبات
- **نجح:** الاختبارات المنشورة (5 تواريخ مرجعية مستقلة) + مقارنة 305 تاريخًا بتنفيذ مستقل = 3355 مقارنة، وكلها تطابق.
- **لم يثبت بعد:** المطابقة لموقع matrix-destiny.com نفسه (لا أرقام مرجعية متاحة للمقارنة، ومنهجه غير منشور). المصادر المنشورة تتفق مع بعضها على كل ما ذُكر أعلاه، لكن ذلك لا يثبت تطابق المرجع تحديدًا.

## ما يلزم لإغلاق العنصر غير المحسوم والمطابقة الكاملة
أرقام المرجع لتاريخ 11/11/1998 (أو تاريخ إضافي) للنقاط المائلة والشاكرات، لتؤكد أن المرجع يتبع نفس المصادر المنشورة.
