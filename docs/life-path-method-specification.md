## 2. المعادلة الرياضية المعتمدة وخطوات الحساب

### أ. الكود البرمجي المعتمد (من `index.html`)
```javascript
const digSum = n => String(n).split("").reduce((s, c) => s + +c, 0);

function lifePath(d, m, y) {
  let n = digSum(d) + digSum(m) + digSum(y);
  while (n > 9 && ![11, 22, 33].includes(n)) n = digSum(n);
  return n;
}
```

### ب. خوارزمية الحساب رقمًا برقم
1. **الخطوة الأولى — جمع خانات اليوم (Day Digit Sum):**
   $$\text{sum}_d = \text{digSum}(d)$$
   *(جمع أرقام خانات اليوم مرة واحدة، مثل: $15 \rightarrow 1+5=6$، $29 \rightarrow 2+9=11$)*.
2. **الخطوة الثانية — جمع خانات الشهر (Month Digit Sum):**
   $$\text{sum}_m = \text{digSum}(m)$$
   *(جمع أرقام خانات الشهر مرة واحدة، مثل: $11 \rightarrow 1+1=2$، $10 \rightarrow 1+0=1$)*.
3. **الخطوة الثالثة — جمع خانات السنة (Year Digit Sum):**
   $$\text{sum}_y = \text{digSum}(y)$$
   *(جمع أرقام خانات السنة مرة واحدة، مثل: $1995 \rightarrow 1+9+9+5=24$)*.
4. **الخطوة الرابعة — المجموع التراكمي الأولي (Initial Sum):**
   $$n = \text{sum}_d + \text{sum}_m + \text{sum}_y$$
5. **الخطوة الخامسة — حلقة الاختزال وفحص الأرقام الرئيسية (Final Reduction Loop):**
   - طالما أن $n > 9$:
     - إذا كان $n \in \{11, 22, 33\}$: **تتوقف الحلقة فوراً** ويُعتمد $n$ كرقم رئيسي محفوظ.
     - إذا لم يكن $n$ ضمن مجموعة الأرقام الرئيسية: يُختزل بجمع خاناته مجدداً ($n = \text{digSum}(n)$) وتُكرر الخطوة.

## 3. سلوك النظام عند ظهور الأرقام الرئيسية (Master Numbers)

في منظومة عقيق أسترو، يُعامل الرقم الرئيسي في واجهة المستخدم (`renderLP`) كحالة خاصة ثنائية البُعد:

1. **الشارة الرقمية (Number Badge):**
   تعرض الرقم الرئيسي كاملاً: `11` أو `22` أو `33`.
2. **الجذر الفيثاغورسي والعنوان (Base Root & Title):**
   تعتمد مصفوفة التحويل الفيثاغورسية المباشرة:
   ```javascript
   const LP_BASE = { 11: 2, 22: 4, 33: 6 };
   ```
   ويُعرض العنوان مدمجاً:
   $$\text{Title} = \text{BaseTitle} + \text{" (رقم رئيسي " + lp + ")"}$$
   - الرقم `11`: يحمل صفات الرقم 2 (الدبلوماسي والشريك) مع إضافة لقب `(رقم رئيسي 11)`.
   - الرقم `22`: يحمل صفات الرقم 4 (الباني والمؤسس) مع إضافة لقب `(رقم رئيسي 22)`.
   - الرقم `33`: يحمل صفات الرقم 6 (المسؤول والمعلم) مع إضافة لقب `(رقم رئيسي 33)`.
3. **المحتوى التفسيري التفصيلي للأقسام:**
   يتم تحميل نصوص الأرقام الرئيسية المتخصصة مباشرة من:
   - `LP_FREE_MASTER[lp]` للملخص العلوي.
   - `LP_MASTER_SOURCE_1_3[String(lp)]` للأقسام من 1 إلى 3.
   - `LP_MASTER_SOURCE_4_7[String(lp)]` للأقسام من 4 إلى 7.

## 5. حالة الدالة المهجورة `calculateLifePath` في `numerology-matrix.js`

- **الموقع:** [`assets/js/numerology-matrix.js`](../assets/js/numerology-matrix.js#L819)
- **الكود:**
  ```javascript
  calculateLifePath: date => {
    const eng = window.AqeeqMatrixMethodAdapter || window.MatrixMethodAdapter;
    return eng ? { number: eng.reduceArcana(new Date(date).getDate()) } : { number: 1 };
  }
  ```
- **الحالة التوثيقية الرسمية:**
  - **مهجورة وغير مستخدمة (Deprecated & Inactive Stub):** لا يتم استدعاؤها في أي مكان داخل واجهة المستخدم أو اختبارات النظام.
  - تم توثيقها بتعليق JSDoc تحذيري يوضح أنها مهجورة، ومحفوظة فقط لعدم كسر أي تكامل خارجي قديم (Backwards Compatibility).
  - المصدر الحصري لمسار الحياة يظل دالة `lifePath(d, m, y)` في `index.html`.
