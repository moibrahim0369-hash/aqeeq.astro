# خانات محتوى مسار الحياة: مخطط شات النصوص

القاعدة: لا نص مُخترَع في الكود. الخانة الفارغة لا تُعرض (لا نص بديل)، والخانة المكتملة تظهر تلقائياً.
الأطوال بعدد الحروف (حقل `content` فقط)، مستخرجة من متوسط الأرقام المكتملة الحالية.

## 1) التعبير 4 و5 و6: `name_data.json` ← `groups.expression.numbers["4"|"5"|"6"].cards[]`
البنية الحالية: `{ "number", "is_master": false, "cards": [ {id,title,content}, ... 3 بطاقات ] }`

| id | العنوان الحالي | الحالي (4 / 5 / 6) | الهدف |
|---|---|---|---|
| "1" | الجوهر والموهبة الفطرية | 830 / 772 / 876 | 1,100–1,200 |
| "2" | الظل العملي والرسالة | 413 / 388 / 446 | 1,200–1,300 |
| "3" | مفتاح التوازن العملي | 339 / 385 / 419 | 950–1,050 |

المجموع المستهدف للرقم: ~3,700–3,850 (الأرقام الأخرى 3,610–3,870).
ملاحظة: عنوان البطاقة 3 فيه كلمة «مفتاح» وهي ممنوعة في نصوص الموقع؛ يُستبدل عنوان البطاقة 3 في الأرقام كلها بعنوان بلا «مفتاح».

## 2) رقم النضج 11 و22 و33: `name_data.json` ← `maturity_extra.numbers["11"|"22"|"33"]`
```json
{ "number": 11, "title": "", "subtitle": "", "sections": [ { "title": "", "content": "" } ] }
```
الخانة المكتملة (أي `section.content` غير فارغ) تتقدم على النص الموسوعي الحالي لنفس الرقم.
الحالي: 11 = 564 حرفاً، 22 = 842، 33 = لا يوجد. باقي الأرقام ~1,050–1,140 مجموع `content`.
الهدف: 4 أقسام لكل رقم بالأطوال التقريبية (429 / 309 / 232 / 161 هي نمط الأرقام 1–9):
القسم 1: 400–450، القسم 2: 300–330، القسم 3: 220–250، القسم 4: 150–180 (المجموع 1,100–1,200).

## 4) الشهر الشخصي: `name_data.json` ← `personal_months.numbers["1".."9","11","22"]`
```json
{ "number": 1, "title": "", "sections": [ { "title": "", "content": "" } ] }
```
11 خانة. المقترح: 3 أقسام (نبض الشهر / ماذا تفعل / انتبه لـ)، 230–300 لكل قسم، المجموع 700–900
(السنة الشخصية الحالية 1,160–1,500 في 4 أقسام).

## 5) اليوم الشخصي: `name_data.json` ← `personal_days.numbers["1".."9","11","22"]`
نفس البنية. المقترح: قسمان (طاقة اليوم / كيف تتصرف فيه)، 170–250 لكل قسم، المجموع 350–500.

## قواعد الحساب
- الشهر الشخصي = السنة الشخصية (1–9) + رقم الشهر الميلادي، ثم الاختزال مع حفظ 11 و22.
- اليوم الشخصي = الشهر الشخصي + رقم اليوم، بنفس القاعدة.
