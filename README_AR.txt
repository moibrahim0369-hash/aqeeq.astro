عقيق أسترو | حزمة معاينة GitHub Pages
======================================

الملفات الأساسية:
- index.html: صفحة الموقع مع قسم حاسبة توافق مسارات الحياة.
- styles.css: أنماط الصفحة المستخرجة بالترتيب من النسخة المعتمدة للمعاينة.
- app.js: ربط واجهة الحاسبة بمحرك عقيق أسترو وملف البيانات.
- engine.js: محرك الحساب المعتمد.
- data.json: قاعدة بيانات التوافق المعتمدة والمرجع النهائي للمحتوى.

طريقة التجربة:
1. ارفع كل الملفات الموجودة في هذا المجلد إلى جذر فرع GitHub Pages التجريبي، مع الحفاظ على الأسماء.
2. افتح رابط GitHub Pages بعد اكتمال النشر.
3. ادخل إلى «حاسبة توافق مسارات الحياة والشراكات القدرية»، وأدخل اسمَي الطرفين وتاريخَي الميلاد، واختر نوع العلاقة.
4. يجب أن يظهر مؤشر النتيجة وكروت مسار الطرفين والجسر الأساسي واليومي ومحتوى الجذب.
5. اضغط «عرض التقرير التفصيلي» لمعاينة الأقسام الموسعة. هذا زر معاينة فقط وليس نظام دفع.

ملاحظات:
- يجب تشغيل الصفحة من استضافة HTTP/HTTPS مثل GitHub Pages؛ فتح index.html مباشرة من مدير الملفات يمنع fetch من تحميل data.json في بعض المتصفحات.
- data.json هو المرجع النهائي للمحتوى. الحسابات تتم داخل المتصفح.
- الصفحة الأصلية تحتوي أيضًا على ميزات فلكية أخرى. لم يتم تغيير منطقها في هذه الحزمة، وقد تعتمد بعض هذه الميزات على موارد منفصلة كانت تُحمّل باسم astronomy.min.js أو ملفات PWA. هذه الحزمة تركّز على ربط حاسبة توافق مسارات الحياة بملف engine.js وdata.json.
- درجة التوافق رقم داخلي في منهج عقيق أسترو وليست قياسًا علميًا أو ضمانًا لنجاح أي علاقة.
